# About HaloStory

**HaloStory** is an AI character interaction platform developed by **R8KStudio**. It allows users to chat with AI-powered fictional characters, build simulated relationships, and explore character-driven stories through an immersive messaging experience.

---

## Features

- **AI Character Chat** — One-on-one conversations with a variety of fictional characters.
- **Group Chat** — Multi-character conversations with multiple AI personalities.
- **System AI & BYOK** — Use built-in AI models or bring your own API key for custom AI providers.
- **Bond System** — Build simulated relationships with characters through XP-based leveling, milestone choices, and relationship labels.
- **Character Stories** — View Fanmade image story posts from characters.
- **Calendar** — Track character birthdays and events.
- **Privacy no-1** — **we can't read your data.** that's it... nothing else :3.
- **Multi-language Support** — English, Indonesian, Chinese, Japanese, Korean.
- **Multi-platform** — Android, iOS, Windows, Web.
- More added later :)
